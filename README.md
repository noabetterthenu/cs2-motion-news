# CS2 Pulse — Motion news site

Адаптивный сайт новостей Counter-Strike 2: бело-фиолетовая палитра, Motion-анимации, поиск, категории, автоматическая RSS-лента.

## Бесплатная публикация на GitHub Pages

1. Создайте аккаунт на https://github.com (если его ещё нет).
2. Создайте **Public** репозиторий с именем `cs2-motion-news`.
3. Распакуйте архив и загрузите **все файлы и папки изнутри** в корень репозитория.
4. Откройте **Settings → Pages**. В разделе Build and deployment выберите **GitHub Actions**.
5. Откройте вкладку **Actions**, разрешите запуск workflows, если GitHub попросит.
6. Запустите workflow **Update CS2 news every 30 minutes** вручную через Actions → Update CS2 news every 30 minutes → Run workflow.
7. После успешного запуска workflow **Deploy CS2 Pulse to GitHub Pages** сайт будет опубликован по адресу:
   `https://ВАШ-ЛОГИН.github.io/cs2-motion-news/`

> Важно: репозиторий должен называться `cs2-motion-news`, если не меняете `base` в `vite.config.js`. Для другого имени репозитория поменяйте `base` на `"/ИМЯ-РЕПОЗИТОРИЯ/"`.

## Как работает обновление

- GitHub Actions запускает `scripts/fetch_news.py` каждые 30 минут (UTC).
- Скрипт читает только RSS-ленту HLTV: `https://www.hltv.org/rss/news`. Другие источники не используются. Публикации без даты или старше 14 дней отбрасываются; новости сортируются по дате. Недавно собранные материалы сохраняются между запусками, пока не истекут 14 дней.
- Если данные изменились, GitHub Actions коммитит JSON в репозиторий. Push запускает workflow публикации.
- Открытая страница также перечитывает JSON раз в 5 минут.

**Ограничения:** GitHub Actions расписание может запускаться с задержкой, поэтому ровно минута-в-минуту обновление не гарантируется. RSS-источники могут временно не отвечать или менять формат; в таком случае лента обновится при следующем успешном запуске. «Актуальные» здесь означает публикации за последние 14 дней; для максимально свежей ленты этот период можно уменьшить в `scripts/fetch_news.py` (`MAX_AGE_HOURS`). Google News RSS — агрегатор ссылок на публикации, а не гарантия полноты новостной картины. Сайт показывает краткие описания и ведёт на оригиналы.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Для ручного обновления новостей (Python 3.10+):

```bash
python scripts/fetch_news.py
```

Затем:

```bash
npm run build
npm run preview
```

## Изменение источников

Список источников и поисковых запросов находится в `scripts/fetch_news.py` в переменных `SOURCES` и `QUERIES`. Добавляйте только RSS-адреса, которые разрешают автоматическое чтение.
